# Evaluation Criteria - ScamShield AI

| Objective / Requirement ID | Evaluation Criterion | Capability Bucket | Measurement Method | Metric | Threshold | User / Business Outcome |
|---|---|---|---|---|---|---|
| O3 / NFR2 | Phishing Email Classification Performance | Domain-specific capability | Evaluate the trained model on a held-out labelled test dataset containing phishing/spam and legitimate emails. | Macro F1-score | ≥ 0.80 | Users receive reasonably reliable email classifications, helping them identify potentially suspicious messages. |
| O3 / RAI1 | Phishing Detection Safety | Domain-specific capability | Compare predicted labels with actual labels and identify phishing/spam emails incorrectly classified as legitimate. | False Negative Rate (FNR) | ≤ 10% | Reduces the risk of users trusting potentially dangerous emails that the system fails to identify. |
| O3 / RAI2 | Legitimate Email Classification | Domain-specific capability | Evaluate legitimate emails in the held-out test dataset and count those incorrectly classified as phishing/spam. | False Positive Rate (FPR) | ≤ 10% | Reduces unnecessary warnings and helps users avoid treating legitimate emails as suspicious. |
| O2 / FR3 | Prediction Result Clarity | Instruction-following capability | Test the application with a set of valid email inputs and check whether each result displays a classification and a confidence score when supported by the model. | Complete result display rate | 100% | Users can understand the system's prediction and its indicated confidence without needing technical knowledge. |
| O2 / NFR1 | Classification Response Time | Cost and latency | Measure the time between submitting an email and displaying the classification result across 100 test emails. | 95th percentile response time (p95) | ≤ 3 seconds | Users can check suspicious emails quickly without unnecessary waiting. |
| O2 / RAI3 | Email Privacy | Instruction-following capability | Inspect the application's data handling and test whether submitted email content remains stored after the prediction is completed. | Unintentionally retained email submissions | 0 | Helps protect users' privacy by preventing unnecessary retention of potentially sensitive email content. |
